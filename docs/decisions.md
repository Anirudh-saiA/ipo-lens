# Decisions

Each entry: the choice, and why.

## Milestone 0 (2026-11-03)

- **Postgres image `pgvector/pgvector:pg16`.** Official pgvector build on Postgres 16; free and open source.
- **Host port 54329.** Ports 5432-5434 and 55432 are taken by other local Postgres instances on the development machine. Configurable via `POSTGRES_PORT`.
- **Surrogate `id` on every table.** The brief lists no id for `pages`, `subscription_snapshots`, `gmp_snapshots`, `lockins`, `doc_diffs` and `chunks`; a bigint `id` primary key is added so rows can be referenced and cited. Natural keys get unique constraints where they exist (`pages`: document_id + page_no).
- **Source page is NOT NULL** on `extracted_figures`, `risks` and `chunks` (hard rule 2: every figure stores its document and page).
- **Reported vs calculated kept apart.** `extracted_figures` holds reported numbers; `calculated_metrics` holds Python-computed values with `formula` and `input_figure_ids` pointing back to their inputs (hard rule 3).
- **Money and ratios as `NUMERIC`,** never float, so stored figures match the document exactly.
- **Enums as CHECK constraints on text columns,** not Postgres ENUM types, so adding a value is a simple migration.
- **Embedding dimension 384.** Fits small free local models such as bge-small-en-v1.5. Changing it later is one migration.
- **Migrations autogenerated by Alembic, then reviewed** (vector extension added by hand). A test checks they match the SQLAlchemy models, so drift is caught in CI.
- **Frontend tests with Vitest** (free, MIT).
- **No GitHub remote yet.** Waiting for the owner to create the `ipo-lens` repository.

## Milestone 1 (2026-11-03)

- **pdfplumber for page text and tables** (MIT; its dependencies pdfminer.six, pypdfium2 and Pillow are MIT/BSD/Apache). Docling stays as a second extractor for hard tables, to add only if pdfplumber misses tables.
- **New table `page_tables`.** The brief asks to store tables per page but its data model has no place for them. Each table is stored as found (rows as JSON, cell text untouched apart from trimming), with page number, position and the extraction method, before any interpretation.
- **Page numbers are 1-based PDF page indexes,** as shown in a PDF viewer's page box. Printed page numbers in a prospectus differ (the cover pages are unnumbered); citations will show the PDF page, and the printed number can be added later if users need it.
- **Ingestion is idempotent by sha256** and all-or-nothing: a document is committed only if every page was stored, so the stored page count always matches the PDF.
- **Tests use a separate `<db>_test` database,** created automatically, so migration tests never delete ingested documents.
- **Test PDFs are generated with reportlab** (BSD, dev only) instead of committing a real prospectus to the repo.
- **Ingestion is a command-line step for now** (`python -m app.cli ingest`). An upload endpoint and fetching from SEBI URLs come later; fetching needs rate limiting and caching per hard rule 9.

## Milestone 2, first pass on one prospectus (2026-11-03)

Started with the BCSSL RHP only, by choice; the gate needs 3 to 5 prospectuses, so it is not passed yet.

- **Figures come from the restated statement tables** (profit and loss, assets and liabilities, cash flow), found by the title at the top of the page. In BCSSL these are on pages 90 to 92. Other tables that repeat the same lines (KPI tables, ratio notes) are not used as sources, to avoid double counting.
- **Periods are read from the dates in the page header, not from column positions,** because extracted columns are often offset from their headers (page 91). A row is used only if it has exactly one value per period; otherwise it is skipped, not guessed.
- **Where a header prints the day apart from the month, the period ends on the last day of that month.** Restated periods in Indian prospectuses end on month ends.
- **Period labels:** `FY2026` (year to 31 March), `3M ended 2026-06-30` (part year), `as at 2026-03-31` (balance sheet).
- **A dash in a cell means nil** in prospectus tables. It is not stored as a figure, so a ratio needing it is skipped rather than computed with zero.
- **Basis:** `restated_consolidated` if the statement titles say so; `standalone` only when the document says it has no subsidiaries, or says standalone (BCSSL: page 406); otherwise `other`.
- **`calculated_metrics` gained `document_id`, `period`, `unit` and `note`** (migration 0003). The brief's columns cannot say which document or period a ratio belongs to.
- **Definitions:** EBITDA = profit before tax + finance costs + depreciation and amortisation. Adjusted EBITDA = EBITDA - other income (the RHP's own definition). Total debt = non-current + current borrowings, excluding lease liabilities (as in the RHP's ratio note). ROE uses average opening and closing equity; RoNW uses closing net worth.
- **Part-year ratios are labelled "not annualised".** ROE is skipped where the opening equity is not in the document (FY2024 here).
- **Not computed yet:** ROCE, because the RHP's capital employed uses tangible net worth and deferred tax liability, which are not extracted yet. Operating cash flow is extracted but not used in a ratio yet.
- **Accuracy counts a difference of 0.01 or less separately as "rounding",** never as exact. Example: the RHP's own total debt of 2,736.91 is 0.01 above the sum of its rounded borrowings lines (2,736.90).
